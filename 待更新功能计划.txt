------------------------------------
一、需求拆解（原始 4 条）
------------------------------------
1. 为用户账号提供「自定义头像」功能：登录后可为自己的账号设置头像，不再只用系统默认头像。
2. 头像格式支持 PNG / JPG / JPEG 等常见图片格式（并可预留 WebP / 静态 GIF 首帧）。
3. 头像数据存储在「本地存储」中（见第四节存储方案），随账号持久保留，不依赖后端、不进 git。
4. 支持多次更换不同头像：每次选择即覆盖旧头像，并可随时「恢复默认」。

------------------------------------
二、功能目标
------------------------------------
- 登录任一预置账号后，顶栏账号胶囊与账号窗显示该账号的头像。
- 未设置时回退系统默认头像（首字母色块 / 默认图标）。
- 用户可随时「更换头像」并「恢复默认」，结果刷新页面后仍保持，且不同账号之间互不串。

------------------------------------
三、交互流程
------------------------------------
1. 入口：账号窗（顶栏胶囊 → FloatWin 账号窗 .acct）新增「更换头像」按钮 + 当前头像预览。
2. 选择图片：uni.chooseImage（H5 回退 <input type="file" accept="image/png,image/jpeg">）。
3. 校验 + 压缩：见第四节。
4. 预览确认：弹出预览（圆形裁切示意），确认后写入本地存储并即时刷新胶囊 / 账号窗。
5. 恢复默认：一键清除本地头像，回退默认图。

------------------------------------
四、存储方案（关键决策）
------------------------------------
推荐：浏览器 localStorage（按账号隔离，天然绑定当前设备 / 浏览器，契合「本地存储」语义）。
- key：whbis:avatar:<小写账号>      （复用 auth.js 的 normAccount 作主键，与登录态一致）
- value：data:image/png;base64,xxxx 或 data:image/jpeg;base64,xxxx
- 仅存 base64 DataURL，不做任何后端同步；不写入源码 / 不进 H5 产物 / 不进 git。

备选：若坚持「本地项目文本文件」（类似 accounts.txt 的落盘方式），则新建 avatars.txt，
按 账号=base64 行式存储；但该方式无法区分多设备 / 多浏览器，且大段 base64 不便维护，
不建议用于头像，除非仅作离线备份。

------------------------------------
五、技术实现要点
------------------------------------
1. 新增 src/utils/avatar.js（与 auth.js 平级）：
   - normKey(account) → 'whbis:avatar:' + normAccount(account)
   - getAvatar(account) → DataURL | null（null 表示用默认头像）
   - setAvatar(account, dataUrl) / removeAvatar(account)
   - pickAndSave(account)：封装 chooseImage + 校验 + 压缩 + 落库，返回 Promise
   - compress(file, { maxSide = 256, quality = 0.8 }) → DataURL（canvas 等比缩放，控制 ≤ ~200KB）
   - validate(file)：白名单 MIME = image/png | image/jpeg（JPG 即 image/jpeg），超限拒绝并 toast
2. 默认头像：utils/avatar.js 导出 DEFAULT_AVATAR（首字母色块 SVG DataURL 或静态资源）。
3. 渲染统一：顶栏胶囊（.vr-acct）与账号窗（.acct 头像位）均通过 getAvatar() 取图，
   <image :src="avatar || DEFAULT_AVATAR"> 绑定，避免两处逻辑分叉。
4. 与现有 auth 解耦：头像不进 EMBEDDED_ACCOUNTS、不进会话（whbis:session），属纯本地偏好；
   genPass / 登录流程完全不受影响。
5. 边界：选非图片 / 超大文件（> 如 5MB）→ 拒绝并提示；压缩后仍过大 → 降低 quality 重试一次。

八、与既有约定的关系
------------------------------------
